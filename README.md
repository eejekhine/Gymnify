# Gymnify

A free, offline-first workout tracker that runs in your browser. No account, no app store, no tracking. Your data stays on your device.

**Live app:** add the link here once it is on GitHub Pages (https://eejekhine.github.io/Gymnify/).

## What it does

- Log sets with weight, reps and a rest timer
- Gym mode and Home mode: tap Home and the same workout converts to the kit you have
- Build your own routines, or start from the built-in ones
- Weekly plan and goal streak
- Personal records and progress charts
- Body weight, measurements and progress photos (photos stay on your device)
- Works offline once loaded, and installs to your phone's Home Screen

## Run it

It is a single HTML file with no build step. Open `index.html` in a browser, or host the folder anywhere (GitHub Pages works).

## Your data

Everything is saved in your browser's local storage on your device. Clearing site data deletes it, so export or back up anything you care about.

## Tech

Plain HTML, CSS and JavaScript. No framework, no dependencies.
